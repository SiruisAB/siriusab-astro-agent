# 按任务选择主题

本地适配的主题方法，参考 Anthropic theme-factory；没有复制它的示例资产或字体，也不要求其预览 PDF。

先沿用产品已有品牌。需要新的样式方向时，用少量具名 token 明确背景、正文、弱信息、强调、成功/警告/失败和间距；主题应能覆盖普通、悬停、禁用、焦点与窄屏状态。

本工作台优先保留天琴座标识与当前色彩；不因天文主题就强制紫色渐变或大幅增加背景图。不改变窗口非全屏与自适应屏幕的用户约束。

用户要求采用另一主题时给紧凑预览再落实，已有明确选择不重复询问。确认字体是否在目标机器可用，检查正文和图标对比度。主题只是样式，不改变按钮含义、业务逻辑或权限。
