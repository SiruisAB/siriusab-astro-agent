# 表格与科研数据

本文件由工作台适配 Anthropic XLSX 技能：保留公式、缓存与文件完整性经验，去除预装依赖、金融默认配色和强制安装规则。辅助源码、许可证和第三方通知保留。

## 工作流程

1. 明确输入、工作表、列名、单位、缺失值含义和输出。阅读/审查不写入；修改已有文件只处理用户指定区域。
2. 表格处理使用实际可用的 `openpyxl`/`pandas`；读取含公式的模型需要分别检查公式和缓存值。先读 [formulas-and-preservation.md](references/formulas-and-preservation.md)。
3. 原始观测值、单位、坐标、时间系统、误差和来源保留；清洗步骤可追溯，不能把空值改成 0 或把精度截断来迎合版式。
4. 适合在表格内动态重算的结果使用公式；不把需要完整科研代码/专用软件的方法强行替换成 Excel 公式。
5. 写新文件并重新打开，检查行列数、表头、类型、公式范围和关键样本；有可用计算引擎时重算并查看错误报告，缺失时明确缓存/公式求值未验证。

## 输出约束

遵守用户模板、已有表格约定和实际使用环境；不强制科研表格采用财务格式。为新建、供填写的表格标清输入区和单位，示例数据必须标明；不向已有观测数据夹入示例行。
保护已有公式、宏、图形和外部链接，不执行宏、不自动刷新网络数据。只要缺少实际重算或渲染能力，就不能声称“所有公式与显示都正确”。

## 工具边界

`scripts/recalc.py` 在副本上调用 LibreOffice并写回计算缓存，执行会改变输出文件并生成临时 Office 配置；仅在用户授权的任务中、依赖已确认时使用。
先检查源码/帮助和报告语义，不以退出码 0 代替公式检查。不自动安装依赖、降低宏安全设置或编译 Linux shim；本机重算能力未因导入技能而获得验证。
