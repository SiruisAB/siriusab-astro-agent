# 修改已有 Word 文档

本地适配说明，参考 Anthropic DOCX 技能；操作的是用户指定的输出副本。

DOCX/DOTX 是 OOXML ZIP。直接编辑前先检查包内条目、总解压大小、路径与链接，拒绝越界和压缩炸弹；不要把外来文件直接 `extractall` 到项目根目录。使用单独临时目录，重新打包到新文件，不用递归删除或覆盖原文档。

`scripts/merge_runs.py` 可合并格式一致的邻接 run，以便查找；调用前读取脚本及帮助，确认不会改写输入。修改文本时保留其他 run 的格式和关系。

批注涉及 `comments.xml`、扩展信息、关系及内容类型。`scripts/comment.py` 生成的批注还需放置锚点，不能只看到注释文件就认为 Word 中能显示。

修订使用 `w:ins`/`w:del`、作者和时间；删除文字使用 `w:delText`。段落标记的删除有合并语义，接受修订后的空项目符号不一定表示原件有缺陷。只有用户要求时才接受/清除修订，不自行抹去审阅历史。

`scripts/office/validate.py` 的 `--original` 可辅助比较；结构通过不证明渲染正确。XML 变更必须保留命名空间、关系、媒体、样式与内容类型。修改前后分别核验正文和版式，标明未执行的验证。
