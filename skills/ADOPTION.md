## 本地适配

1. 每包基于上游工作流做本地适配并保留 MIT `LICENSE`；补充 `license: MIT`、来源和 `astro-agent-v2` 元数据。
   正文已明确限制换新会话、二分定位、变异测试、回滚和遥测的作用域，不只依赖宿主提示词覆盖。
2. 修正性能示例中两处共享检查表的相对路径；保留已有包内 `references/shared/` 副本。
3. 宿主技能规则明确任务授权：只要求审查、解释或诊断时不改文件。
   变异测试或 `git bisect` 等会改变工作树的验证必须另获授权并使用隔离副本；不清理用户未提交改动。
4. 技能不授权提交、推送、发布、服务重启、依赖安装或回滚；仍经过已有工具与审批。
   禁止将隔离科研子 Agent 用作工程工具执行器。
5. 仅自部署 Qwen Coder390 的请求按服务地址保持并发 1；流式、超时、预算、安全和结构化工具校验不变。
   其他模型渠道不新增全局单并发锁；宿主可并行调度独立只读工作，工作区写入保护仍保持。
   不自动跨渠道发送源码、换模型或增加调用额度。
6. `/compact` 继续使用后端原文归档和摘要版本。技能只指导活动上下文管理，不删除历史或启动第二套压缩。
7. 验证报告区分真实命令结果、模拟测试与未验证的外部依赖；示例性能阈值不是项目实测结果。
8. Code/Agent 可通过 `delegate_tests` 请求一个新 pytest 测试提案。只读白名单源码快照，
   无 Shell、文件写入或递归委派。主 Agent 经原审批应用和执行；旧科研子 Agent 的权限不变。
9. 显式选择已提供正文时 `load_skill` 返回加载凭据，避免重复占用上下文；`reload=True` 可重新获取。
   未显式选择的自动加载仍完整返回说明，保证新的上下文阶段不会丢失指南。

## 使用

工作台顶部“技能” → 刷新 → 查看名称、完整说明、资源、许可及包校验值。
本次已审阅的 6 个包在本机启用；可勾选最多 3 个用于下一条消息，发送后清除选择。
模型也能从名称/用途目录自动选择相关技能，再完整加载正文；不一次性注入所有正文。

例如修复错误可选择调试与测试技能；核验 LangChain 接口可选择文档核验技能；
优化启动速度可选择性能优化技能；仅审查修改可选择代码审查技能。

启用状态是本机数据库状态，不随源码分发。新机器上的包默认未启用，须在界面审阅后启用；
任何包资源变更都会使新加载失效。宿主规则更新需要重启后台服务，不能中断正在执行或等待审批的任务。

### 实际适配

- 重写新增技能的短入口，把格式细节放入按需参考；描述按中文任务区分，不因文件名被随口提到而同时加载全部技能。
- 删除“依赖已预装/缺失即自动安装”、固定 Linux 命令、Claude 连接器和无条件新开读者会话的假设。
- 不把字体、财务格式、PPT 装饰、营销 hero 或固定框架变成科研工作台的通用要求。
- 前端验收等待实际元素/状态并设置超时；SSE/WebSocket 页面不强制等待 `networkidle`。
- Office/PDF 辅助源码仅保留为按需工具，不执行宏、不上传材料、不自动安装依赖；Windows 渲染、Office 重算和各上游脚本仍须实际验证。
- Word/PPT/表格修改默认输出新文件，保护原图、模板、宏、公式、单位、坐标和来源；结构通过与视觉/数值验证分别说明。
- 原来只对自部署 Qwen Coder390 生效的单并发、预算、流式、安全与审批没有变化，其他模型渠道不新增限制。
- `/compact`、原文归档、摘要版本和已加载快照继续由后端统一维护，没有新增记忆系统。
- 用户已要求移除项目测试文件，不恢复 `tests/`、pytest 缓存或历史验收目录；本次必要验证在项目外的临时工作区进行。

### 验证与读取优化

六个新入口均通过 `skill-creator` 格式校验。隔离验证覆盖完整加载、显式正文去重、
六技能上限、资源分页与 CRLF 原文保持、跨包越界拒绝、变更后禁用，以及只注入目录元数据。
新增入口的包内链接均核对存在。没有创建项目测试目录或测试缓存。

`skill_store.no_links` 合并重复的文件状态读取为每层一次 `lstat`；仍检查所有祖先、
解析后的边界和完整包内容哈希，不增加跳过校验的缓存。另用实际 Windows 临时目录
验证正常/尚未创建路径、越界路径、普通/祖先/边界目录联接及失效目录联接拦截，
并确认全部 12 个包的哈希与启用状态不变。
同机三次目录读取的中位数由 0.806 秒降至 0.674 秒；此数字仅代表技能目录读取，
不是模型推理或整体冷启动速度。运行中的后台须在下次重启后加载该代码优化，
技能包本身通过界面刷新即可发现。

六个新技能的格式与宿主加载流程验证后启用。刷新工作台“技能”即可用于下一条消息；
没有常驻注入全文，不要求重启或切换模型。这里的验证不代表已完成 Word/PDF/PPT/Excel
实物输出、渲染和公式重算，也不代表所有辅助脚本都已在 Windows 上运行验证。
